# MyRaíces App Experience v13.0

Mobile-first customer shopping experience layered over the existing stable storefront.

## Included
- Mobile home designed as an app, not a copy of the desktop website
- Intent-based shortcuts: easy meals, calm, sweets and wellness
- Bottom app navigation: Home, Search, Cart, Orders and Profile
- Instant product search
- Mobile featured-product rail with quick add
- Simplified two-column mobile catalog
- Existing Supabase, authentication, cart, waitlist and Square Sandbox preserved
- Desktop experience remains unchanged

## Deployment
No SQL or new environment variables are required. Deploy the full repository as usual.
