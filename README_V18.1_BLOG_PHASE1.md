# My Raíces v18.1 — Blog Phase 1

Incluye la página principal del Blog, vista individual de artículos, categorías, artículos destacados/recientes, newsletter y estructura SEO inicial.

## Instalación
1. Ejecutar `supabase/blog_phase1_v18.1.sql` en Supabase SQL Editor.
2. Subir el repositorio a GitHub/Netlify.
3. Abrir `/blog`.

Mientras no existan artículos publicados en Supabase, el Blog muestra contenido demostrativo local para validar el diseño. En la siguiente fase, NURAI administrará las tablas `blog_articles` y `blog_categories`.
