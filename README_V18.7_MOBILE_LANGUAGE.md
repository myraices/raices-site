# MyRaíces v18.7 — Selector de idioma móvil

## Cambio principal

El selector ES/EN ahora permanece visible en el encabezado de la experiencia móvil compacta, sin necesidad de girar el teléfono ni abrir el menú lateral.

## Detalles

- Reutiliza el selector de idioma existente y su persistencia actual.
- Se muestra como un control compacto junto a cuenta y carrito.
- Incluye ajustes para pantallas de hasta 360 px.
- No requiere cambios en Supabase, Netlify ni variables de entorno.
