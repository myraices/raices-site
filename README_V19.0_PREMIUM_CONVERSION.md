# MyRaíces v19.0 — Premium Conversion Edition

## Objetivo
Evolución visual y comercial de MyRaices.com manteniendo intacta la integración con NURAI CRM Web / Contenido Web.

## Cambios
- Hero premium de dos columnas con composición editorial.
- Franja de confianza con cuatro argumentos comerciales.
- Nueva sección editorial de marca y conversión.
- Jerarquía tipográfica, espacios, tarjetas y fondos refinados.
- Mejoras responsive sin alterar la experiencia PWA móvil existente.
- Nuevos textos bilingües ES/EN.
- Cache busting del nuevo CSS.

## Compatibilidad preservada
- Los selectores CMS de anuncio, hero y colecciones permanecen sin cambios.
- No se modificaron Supabase, Square, Brevo, autenticación, carrito, catálogo, inventario, pedidos, waitlist ni funciones Netlify.
- NURAI v19.0.5 no requiere cambios para esta entrega.
